# Recorder — `gui_recorder.py`

`gui_recorder.py` is a background application that sits in the Windows system
tray, highlights the GUI element under your cursor in real time, and converts
every click and keystroke you make into a ready-to-run `gui_live.py` script.

---

## Starting the recorder

```bash
python gui_recorder.py                        # default hotkeys, output = recorded.py
python gui_recorder.py -o login_flow.py       # custom output file
python gui_recorder.py --start F6 --stop F8   # custom hotkeys
```

A small tray icon appears in the Windows notification area (bottom-right).

---

## Tray icon states

| Icon | State |
|---|---|
| Green circle with **R** | Idle — waiting to record |
| Red circle with **R** | Recording — capturing events |

---

## Controls

### Hotkeys

| Key | Action |
|---|---|
| **F7** (or `--start`) | Start recording |
| **F9** (or `--stop`) | Stop recording and save the script |
| **Esc** | Cancel recording — discards all events, nothing is saved |

### Tray right-click menu

| Item | Action |
|---|---|
| ▶  Start Recording (F7) | Begin a recording session |
| ■  Stop Recording (F9) | End session and write the output script |
| ✕  Cancel (discard) | End session without saving |
| 📄  Open last script | Open the output file in Notepad |
| Exit | Quit the recorder |

Double-clicking the tray icon starts or stops the current session.

---

## What is recorded

| Action | Generated call |
|---|---|
| Left click on element | `s.click('path')` |
| Right click on element | `s.right_click('path')` |
| Typing into a field | `s.set_text('path', 'text')` |
| Modifier + key (Ctrl+S) | `s.hotkey('ctrl', 's')` |
| Named keys (Enter, Tab, …) | `s.press('enter')` |
| Pause between actions | `time.sleep(N)` |

### What is NOT recorded

- Mouse movement (only the final hover position when a click occurs)
- Scroll wheel events
- Window resize / move
- System-level actions outside accessible windows

---

## Live highlight

While recording is active:

- A **green border** tracks the element under your cursor
- A **tooltip** near the cursor shows the element's path, e.g.:
  ```
  File||MenuItem
  Untitled - Notepad||Window->File||MenuItem
  ```

The highlight is click-through — it does not interfere with the application
you are recording.

---

## Generated script format

The output script imports `gui_live.py` and is ready to run with a single edit
(update the window title in `connect_application`):

```python
"""
Auto-generated by gui_recorder.py
"""
import time
from gui_live import connect_application

# TODO: update title to match your target window
s = connect_application(title="...")
s.focus()

s.click('Untitled - Notepad||Window->File||MenuItem')
s.click('Save As||MenuItem')
s.set_text('File name:||Edit', 'report.txt')
s.click('Save||Button')
time.sleep(1.2)
s.hotkey('ctrl', 'z')
```

## Command-line options

```
python gui_recorder.py [OPTIONS]
```

| Flag | Default | Description |
|---|---|---|
| `-o / --output FILE` | `recorded.py` | Path to write the generated script |
| `--start KEY` | `f7` | Global hotkey to start recording |
| `--stop KEY` | `f9` | Global hotkey to stop recording |

Any key name accepted by the `keyboard` package can be used (e.g. `f6`,
`ctrl+r`, `pause`).

---

## Tips

**Slow your actions slightly** — UIA lookup runs every ~150 ms. Very fast
clicks may capture an empty path. A natural interaction pace (one click
per half-second) works perfectly.

**Record one flow at a time** — start, do exactly the sequence you want,
stop. Edit the connection line, then run the script.

**Combine with `UIPath`** — after generating the script, wrap repeated
window prefixes in a `with s.path(...)` block to clean up verbose paths.

**Fallback without pystray** — if `pystray` is not installed the recorder
runs in CLI mode: hotkeys still work, but there is no tray icon or menu.

## Architecture

```
Main thread       pystray icon (Win32 message loop)
TkOverlay thread  Tkinter overlay (green strips + tooltip)
TrackThread       polls cursor every 80 ms → UIA from_point → path → TkOverlay queue
ClickThread       polls GetAsyncKeyState at 10 ms → ClickEvent
keyboard hooks    keyboard package threads → TypeEvent / HotkeyEvent
```

All events are appended to a thread-safe list protected by a `threading.Lock`.
The `generate_script()` function converts the list to Python source on stop.
